# 学术文献收集（Literature Collection）

把一次文献调研任务转化为"可核查、可复用、可对比"的结构化文献清单。适用于单主题文献综述收集、跨国/跨地区政策文献对比收集、论文清单合并等场景。

## 工作流程

### 0. 输入确认
确认并明确以下要素（用户未说明时先问或采用合理默认）：
- **主题与范围**：如"欧盟近岸养殖政策"；明确收录类型（默认：政策/治理/规制类学术论文，排除纯生物/技术类、灰色文献、非目标区域文献）。
- **数量要求**：如"至少 30 篇"（达标即可，宁缺毋滥）。
- **语言**：是否需要非英文文献（如日语/中文），及著录格式（如日文条目按"日文著者(年). 日文标题. 日文期刊, 巻(号): 頁"并附英译名）。
- **输出**：清单文件路径 + 是否最终合并总目。

### 1. 检索与核实（核心环节）
- **多轮 web_search**：用多种关键词组合反复检索（英文为主，按需加入日文/中文关键词；示例："EU aquaculture policy"、"maritime spatial planning aquaculture"、"漁業法 改正 養殖"、"海藻養殖 政策" 等）。
- **交叉核实**：以期刊官网、ScienceDirect / Wiley / Nature / MDPI / Frontiers / Springer、J-STAGE / CiNii / researchmap / Semantic Scholar / Scopus 等数据库页面交叉确认作者、年份、期刊、卷期页码、DOI。
- **善用线索**：借用已精读论文的参考文献表（其卷期页码通常可靠）作为初始来源，再逐条检索佐证。
- **DOI 规则**：可确认的给出 doi.org 链接；无法确认的明确标注"DOI 未核实"（可附 ScienceDirect PII 作为检索线索）。
- **严禁编造**：标题、期刊、年份、DOI 必须可被检索结果支撑；作者名单/页码/卷期不确定时如实标注"待核实/以原文为准"。

### 2. 收录与排除标准（示例模板）
- 收录：政策分析、治理、规制、许可/行政程序、空间规划（MSP/AOA/海区）、环境法规约束、社会接受度（social license）、气候变化适应政策、产业振兴政策等相关**学术论文**（研究文章/权威综述/专著章节/重要会议论文可注明类型）。
- 排除：纯生物/养殖技术论文；灰色文献（机构报告，可放附录）；非目标区域专项文献（若收录需加注，如"挪威为 EEA 成员国非 EU"）；重复条目。

### 3. 清单整理与输出
- **分类**：按主题分 5-8 类，每类下列条目（保持原序号连续）。
- **条目格式**：`**作者 (年份). 标题. 期刊, 卷(期): 页码. DOI（或"DOI 未核实"）+ 链接**` + 一句中文点评（该文与主题的关系）。
- **标注约定**：`※` 或"待核实"标注无法确认的字段；Open Access 文献标注（OA）便于下载。
- **文件结构**：标题 → 收集说明（主题/方法/核实原则/语言说明/时间）→ 分类条目 → 统计表（类别×篇数）→ 备注（核实状态、增量说明、下一步建议）。
- **统计表**：类别、篇数（必要时分语言列），合计与要求对比。

### 4. 大规模并行收集（≥2 个地区/主题时）
- 按地区/主题**分派后台子代理**（每个子代理一个自包含 prompt，独立写一个清单文件），一次消息内并行启动多个。
- 子代理 prompt 模板（自包含，不含本会话上下文）：
  ```
  你是一名海洋政策文献研究助手。任务：为"【主题/地区】"收集至少 N 篇学术论文并整理为 Markdown 清单。
  ## 主题范围：【列出具体收录维度】
  ## 检索方法：使用 web_search 工具多轮检索，关键词如【…】；尽量核实作者/年份/期刊/卷期/DOI；【语言要求，如日文条目格式】。
  ## 输出要求：用 write 工具创建文件【路径】；按主题分类（≥5 类）；每条格式【…】+一句中文点评；结尾统计表；至少 N 篇，宁缺毋滥，严禁编造，DOI/卷期无法核实必须标注。
  最后在回复中给出：总篇数、分类统计、语言分布、3-5 篇重点文献简介。
  ```
- 子代理返回后核对：文件存在、条数达标（可用 grep/正则统计条目行数）、标注完整。

### 5. 多清单合并总目（可选）
- 读取各清单 → 生成《XX总目》：
  1. **总表**：按地区/来源分子表，每行：编号（如 EU-01）｜主题｜文献｜期刊卷期｜DOI/链接｜核实状态；
  2. **交叉索引**：主题 × 地区矩阵（每主题列出各地编号 + 一段跨区速读指引/对比看点）；
  3. **各地区 TOP5 重点文献**（快速导读）；
  4. **统计汇总** + 备注（待核实字段提示、OA 下载提示、后续扩展建议）。
- 合并后**校验条目数**（统计各行数量与源文件合计一致）。

### 6. 质量校验
- 数量核对：统计条目数与要求（≥N）及来源合计一致；
- 无编造抽查：抽查若干条 DOI 可解析性；确保所有无法核实的字段都有标注；
- 增量说明：若基于旧清单扩充，注明新增/保留/移入附录的情况。

## 输出模板（清单文件）

```markdown
# 【主题】文献清单（N 篇）

## 收集说明
- 主题范围 / 检索方法 / 核实原则（宁缺毋滥，无编造）/ 语言说明 / 收集时间

## 一、【主题类别一】
1. **作者 (年份). 标题. 期刊, 卷(期): 页码. DOI（或未核实）+ 链接**
   > 点评：一句与该主题的关系。
2. …

## 统计表
| 类别 | 篇数 | … |
| 合计 | N | … |

## 备注
- 待核实字段清单 / OA 标注 / 下一步建议
```

## 注意事项
- **宁缺毋滥**：数量要求只是下限，检索支撑不足时如实汇报缺口（如"日文文献因作者无法核实未收录"），不强行凑数。
- 检索不到某字段时不要推测；PII/文章号可作检索线索但不算已核实 DOI。
- 大范围任务优先并行子代理；小范围（≤15 篇）可自行完成。
- 本技能专注"收集与整理"；对单篇文献的精读分析请使用 `literature-reading` 技能。
