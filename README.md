# 近岸养殖政策文献总目与工具（Coastal Aquaculture Policy）

中欧美日加墨韩挪澳新智印越印尼巴西南非等 **16 个地区、271 篇近岸/沿海水产养殖政策文献**的总目、检索工具与自动化下载技能。

> ⚠️ 本仓库仅含**文献元数据与工具**（标题/期刊/DOI/链接），**不含任何受版权保护的论文 PDF 全文**；全文请通过机构订阅（CARSI）、开放获取或图书馆文献传递获取。

## 快速上手

**1. 导入 Zotero**：`zotero_import_271.ris` → Zotero `文件 → 导入`；OA 全文用"查找可用的 PDF"自动抓取。

**2. 批量下载知网中文论文**（cnki-download 技能）：
```powershell
py -3 .dsh/skills/cnki-download/scripts/cnki_download.py --list 文献传递申请清单.csv --out pdfs_cn
```
- 首次运行浏览器弹出，完成 CARSI 机构登录（登录态持久化，之后自动复用）
- 自动逐篇检索→匹配→下载 PDF/CAJ，含容错与日志

**3. 生成/更新元数据**：`_scripts/build_ris_271.py`（总目→RIS）、`build_csvs.py`（清单→CSV/对照表）。
