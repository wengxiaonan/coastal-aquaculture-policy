🚀一次真实的合作是什么样的？

比如你跟我说："帮我搭个 Web 服务器，部署到远程 Linux 上。"

我的流程是：

  1. 先问你几个关键问题（服务器在哪、用什么技术栈、怎么部署）
  2. 拿到连接信息后测试 SSH 连接
  3. 检查环境 → 装 Node.js → 写代码 → 配置守护进程
  4. 最后用 curl 验证接口，告诉你"服务已上线 ✅"

全程你只需要确认几个选择，剩下的交给我。
